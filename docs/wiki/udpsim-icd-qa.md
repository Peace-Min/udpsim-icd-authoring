# UdpSim ICD Skill QA

현재 QA는 도구 정확성, 모델의 작업 수행, 사내 실제 환경 인수를 분리한다.
무료 모델을 사용한 실제 정의 작업의 방법과 집계는 [OpenCode Skill QA](udpsim-opencode-skill-qa.md)에 기록한다.
입력 12종과 직접 도구 실행·중단/재개 보강은 [우선순위 QA](udpsim-priority-qa.md)에 기록한다.
2026-11-02 현재 Codex의 독립 에이전트로 수행한 [원본부터 Core까지의 자율 완주 8건](udpsim-codex-autonomous-qa.md)은
통과했다. 모델 실행과 부모의 독립 정답/패킷 대조를 구분하며 사내 Qwen 인수는 여전히 NOT_RUN이다.
한 단계의 통과를 다른 단계의 통과로 표현하지 않는다.
[사용 안내](udpsim-icd-authoring.md)와
[모델 시험 절차](../../skills/udpsim-icd-authoring/references/model-qa.md)를 참고한다.

## 시험 계층

1. **결정적 도구 시험**: 합성 정의의 중간 JSON 검사·XML 변환·실제 Core 검증,
   독립적으로 계산한 payload와 실제 Core 해석 결과를 비교한다. 정상 입력뿐 아니라
   누락·길이 불일치·비트 겹침·ID 오류·기대 값 불일치·없는 도구의 실패도 확인한다.
2. **독립 에이전트 수행 시험**: 정답을 전달하지 않은 새 에이전트가 실제 Skill과
   합성 원본만으로 작업한다. 생성물을 별도 정답과 대조한다. 이 시험은 해당
   에이전트의 결과이며 Qwen 통과를 의미하지 않는다.
3. **외부망 동일 모델 시험**: 실제 `qwen3.6-27b` API 또는 동일 가중치의 GPU
   실행 환경에서 합성 작업과 검증 피드백을 준다. 서비스 모델은 사내 가중치·
   양자화·추론 설정과 다를 수 있으므로 인터페이스와 설정을 함께 기록한다.
   Bifrost를 로컬에 연결해도 사내 모델 서빙 환경까지 같아지는 것은 아니다.
4. **사내 인수 시험**: 실제 Claude Code **2.1.312**와 Bifrost 경유 요청 모델
   **qwen3.6-27b**에서 명령 발견·도구 사용·수정·중단 복구까지 시험한다.
   API 추출 시험만으로 Claude Code 통합 시험을 대체하지 않는다.

## 로컬 재현 범위

2026-10-30 확인한 개발 PC는 RAM 약 16GiB, GT 1030 2GiB, Ollama에
`qwen2.5-coder:7b`가 있으며 Claude Code CLI는 **2.1.109**다.
사내 모델·Claude 버전과 다르므로 **7B 모델은 사용자가 요청한 동일 모델 시험의
대체 수단으로 사용하지 않는다.** 7B 실행은 취소했으며 모델 응답에 대한 통과
판정도 없다. 외부망의 실제 27B API와 로컬 Bifrost 조합 또는 GPU 모델 실행 환경은
계정·접근 경로를 정한 뒤 시험한다. 인터넷 차단·시간 제한·오류 응답 같은 조건을
별도로 시험해도 실제 Bifrost의 모든 동작을 재현한 것은 아니다.

사내 관측 환경의 컨텍스트 상한은 입력·출력 합계 **262,144 토큰**이며 초과 시 500이
발생할 수 있다. Opus/Sonnet/Haiku 별칭이 같은 모델을 가리키므로 별칭을 바꾸는 것을
독립 모델 교차 검증으로 기록하지 않는다. 원본을 메시지 단위로 나누고 파일로
진행 상태를 남긴다. 게이트웨이 주소·인증 정보는 공유 시험 보고서에 기록하지 않는다.

## 실행 결과 기록

아래 상태는 실행 증거가 도착한 뒤 갱신한다. 계획된 시험은 통과로 세지 않는다.

| 시험 | 상태 | 근거 |
| --- | --- | --- |
| 중간 정의·XML·payload 도구 | PASS | IR 50건·하네스 20건·payload 25건, 실제 Core XML 통과 |
| 독립 에이전트 수행 | PASS, 범위 제한 | 소스·문서 텍스트 발췌 성공, 불명확 소스 차단 |
| 외부망 동일 모델 | NOT_RUN | 실제 27B 미실행 |
| 사내 Qwen·Claude Code 인수 | NOT_RUN | 사내 조합에서 실행하지 않음 |

OpenCode 무료 대리 모델의 실제 본시험 36건은 GLM **10/12**, Nemotron **7/12**,
Flint **1/12** 통과였다. 원본/응답 오류 3건과 호출 실패 15건을 포함하며 전 항목 통과는 아니다.
실제 PDF 텍스트 추출·의존성 참조와 Core/패킷 대조까지 수행한
[상세 결과](udpsim-opencode-skill-qa.md)를 참고한다. 사내 인수 상태는 그대로 NOT_RUN이다.

플러그인 manifest는 로컬 Claude Code CLI 2.1.109에서
`claude plugin validate .` 종료 코드 **0**을 확인했다. 이는 manifest 검사이며
사내 버전의 명령 발견·모델 도구 사용 시험과는 다르다.

2026-10-30 도구 시험 결과:

- `python -m unittest discover -s tests -p test_udpsim_ir.py`: **50건 통과**.
  미확정·근거 누락·타입·중복·폭·길이·순환·전개 한도·원자적 출력과
  **65,507바이트·구조체 32단계**의 허용 경계를 확인했다.
- 합성 `tests/fixtures/udpsim-ir/synthetic.json`을 `icd_tool.py convert`로 변환한 뒤
  `Test-IcdXml.ps1`로 실제 Core를 실행해 **XML_PASS**를 확인했다. Send/Receive
  각각 13바이트이며 수동 헤더와 구조체 배열·Bits 경로의 오프셋도 표시됐다.
- Core 연결기의 음성 경로는 없는 MSBuild에서 **종료 2 / BLOCKED_ENV**,
  필수 헤더 역할이 없는 XML에서 **종료 1 / XML_FAIL**을 확인했다.
- `tests/udpsim-packet-fixtures.ps1`을 Windows PowerShell **5.1**에서 실행해
  최종 **25건 통과**했다. 독립 검토에서 발견한 이전 성공 보고서 잔존 문제를
  수정하고, payload·빌드 도구 누락 및 잘못된 ICD에서 현재 실패 보고서로
  갱신되는지 재검사했다. 보고서 경로의 입력 덮어쓰기·구현 경로·심볼릭 링크
  통과를 제한한다. 원시 증거는 무시되는 `out/udpsim-packet-tests-*/`에 있다.
- `python -m unittest discover -s tests -p test_udpsim_model_eval.py`: **20건 통과**.
  가짜 HTTP 서버로 Ollama/OpenAI/Anthropic 응답 처리, thinking 선행 응답,
  도구 요청 거부, 타임아웃·500·컨텍스트 초과와 제한된 재시도, 길이 오류 수정
  피드백, 안전한 미확정 종료와 완료 상태 재개를 검사했다. 검증기·정답 변경 시
  재개 거부, 저장된 산출물 재검증, 중복 JSON 키·비정상 숫자 거부도 확인했다. 이는 **하네스 시험**이며
  실제 모델 성능·Claude Code 도구 사용·Bifrost 실물 호환 통과가 아니다.
- Python skill validator 통과, PowerShell 스크립트 파서 오류 0건을 확인했다.
  이 검사는 지시문 의미나 실제 모델의 수행 성공을 보장하지 않는다.

독립 에이전트는 합성 소스를 정의로 변환하고 실제 Core의 `XML_PASS`를 확인했다.
**문서 텍스트 발췌**는 IR 검사·XML 생성 후 별도 정답과 일치함을 확인했다.
불명확한 합성 소스는 미확정 항목을 남기고 XML 생성을
차단했다. **PDF 파일 추출·OCR·실제 PDF 페이지 탐색은 시험하지 않았다.**

도구 소스가 수정되면 이 집계와 관련 시험을 다시 확인한다. 모델 시험 결과는
기계적 검사와 독립된 상태로 계속 기록한다.

최종 통합 실행은 `tests/validate-udpsim.ps1 -UdpSimRoot <checkout>`에서
`LOCAL_TOOLS_PASS`를 확인했다. 은행 기본 회귀 검사 `tests/validate.ps1`도
종료 0이며, 이 명령의 선택형 대형 검사는 실행하지 않았다.

원시 명령·출력·모델 응답·소요 시간·종료 코드는 무시되는 `out/` 작업 경로에 남긴다.
공유 Wiki에는 합성 입력의 재현 명령, 집계와 한계를 적으며 전체 로컬 경로나
실제 사내 규격에서 파생된 필드·값·패킷은 복사하지 않는다.

## 외부망 동일 모델과 무료 할당량

이 PC의 격리 설치와 모의 연결 시험은 [클라우드 QA 환경](udpsim-cloud-qa.md)에
기록한다. Claude Code 2.1.312와 Bifrost v2.4.0을 설치했으며, 실제 모델의 품질
시험 상태와 클라이언트·게이트웨이 연결 상태를 따로 확인한다.

실제 27B 실행 경로는 Alibaba Cloud Model Studio API와 로컬 Bifrost 연결 또는
GPU 환경의 동일 모델 실행이다. 해당 27B의 실제 클라우드 호출은 하지 않았다.
OpenCode 무료 대리 모델의 실제 호출·정의 작업은 [별도 시험](udpsim-opencode-skill-qa.md)이다.
외부 API만 호출한 결과는 추출 품질 시험이며 Claude Code의 명령 발견·권한·도구
실행 시험을 대체하지 않는다.

2026-10-30 확인한 [공식 모델 가격 안내](https://help.aliyun.com/en/model-studio/model-pricing)는
`qwen3.6-27b`에 대해 **Beijing 지역의 무료 100만 토큰·90일** 조건을 안내한다.
[무료 할당량 안내](https://help.aliyun.com/en/model-studio/new-free-quota)에 따르면
다른 지역에는 이 무료 할당량이 적용되지 않는다. 실제 계정의 대상 여부·잔여량·
유효기간을 콘솔에서 확인해야 하며, 미래의 모든 QA가 무료라는 뜻은 아니다.
호출 전에 **FreeQuotaOnly**를 설정해 무료분 소진 후 자동 유료 사용을 막는다.
계정 접근과 적용 여부를 확인하기 전에는 무료 시험 가능으로 확정하지 않는다.

## 반입 후 인수 기준

실제 사내 환경에서 아래 사례를 각각 **새 세션 3회** 실행하고 모든 결과를 기록한다.

- 소스 정의 추출 → IR 검사 → XML 변환 → 실제 Core 검사 성공.
- PDF 페이지 구간에서 목록을 찾고 범위 밖 헤더·타입 의존성까지 확인.
- 원본 근거로 수정 가능한 검증 실패를 피드백 받아 수정.
- 정보 부족 또는 상충하는 원본에서 추측하지 않고 확인 필요로 종료.
- 동일 payload의 일치·불일치를 구별하고 구조 확인과 기대 값 비교 범위를 명시.
- 중간에 중단한 작업을 파일 상태에서 이어가며 완료된 메시지를 보존.

필수 사실의 조용한 추측이나 실제 검증 없이 완료 선언이 한 번이라도 나오면 해당
조합은 인수 실패다. 타임아웃·권한 판정 실패·컨텍스트 초과는 환경 실패로 분리하며
성공이나 내용 오류로 바꾸어 세지 않는다. 최대 3회 수정 라운드를 넘기지 않는다.

기록할 항목은 Skill/fixture/UdpSim의 커밋 또는 해시, 요청·반환 모델 라벨,
Claude Code 버전, 실제 명령, 소요 시간, 수정·재시도, 도구 종료 코드와 평가 결과다.
정답 파일은 생성 모델의 입력에서 제외하고, 원본과 결과를 독립적으로 비교한다.
